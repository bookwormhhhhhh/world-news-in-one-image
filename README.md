A Python program (standard library only) that draws a newspaper front page summing up the world news of Thursday 19 November 2026: the International Court of Justice ruling that Myanmar committed genocide against the Rohingya, the United States, China and Russia issuing a joint peace declaration after their first trilateral summit in Shenzhen, Voyager 1 reaching one light-day from Earth, and GTA VI launching after a 13-year wait. It writes a 1024x1024 PNG to /output/entry.png, deterministically and with no network.

## Run it

```sh
python3 main.py
```
